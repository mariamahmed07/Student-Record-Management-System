
# Student Record Management System

A console-based student management application built with C++.

## Features

- Add new student records.
- Display all students.
- Search for students by ID.
- Update student information.
- Delete student records.
- Prevent duplicate student IDs.
- Validate grades between 0 and 100.
- Save student records to a text file.
- Load saved records when the program starts.

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- Vectors and iterators
- File handling

## Requirements

- A C++ compiler supporting C++17 or later.
- CMake 3.20 or later.

## How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE such as CLion.
3. Configure the project with CMake.
4. Build and run the application.
5. Follow the instructions displayed in the console.

## Menu Options

1. Add Student
2. Display All Students
3. Search Student by ID
4. Update Student
5. Delete Student
6. Exit

## Data Storage

Student records are stored in `students.txt`. The program loads existing records at startup and saves changes when records are added, updated, or deleted.
